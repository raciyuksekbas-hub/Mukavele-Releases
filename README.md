# Mukavele

Mukavele, avukatların avukatlık ve hukukî danışmanlık sözleşmelerini kural ve şablon tabanlı olarak hazırlamalarına yardımcı olan bir macOS masaüstü uygulamasıdır.

## Temel özellikler

- Avukatlık sözleşmesi oluşturma
- Maktu, nispi ve karma ücret modelleri
- Taksitli ödeme planları
- Tahliye ve kira bedelinin tespiti süreçleri
- Sürekli hukukî danışmanlık sözleşmeleri
- DOCX belge üretimi
- Yerel ve çevrimdışı veri saklama

## Gizlilik

Mukavele çevrimdışı çalışır. Kullanıcı verileri cihazda yerel olarak saklanır ve yapay zekâ sistemlerine gönderilmez.

## Önemli uyarı

Mukavele tarafından oluşturulan belgeler taslak niteliğindedir. Belgeler kullanılmadan veya imzalanmadan önce kullanıcı tarafından hukukî ve maddi yönden incelenmeli ve son kontrolleri yapılmalıdır.

## Sistem gereksinimi

- Apple Silicon işlemcili Mac
- macOS

KURULUM İÇİN:

1- GitHub bağlantısını açın.
2- Sayfanın altındaki Assets bölümünden Mukavele-1.3.2-arm64.dmg dosyasını indirin.
3- İndirilen .dmg dosyasını açın.
4- Açılan penceredeki Mukavele uygulamasını Applications (Uygulamalar) klasörüne sürükleyin.
5- Kurulum tamamlandıktan sonra Uygulamalar klasöründen Mukavele'yi çalıştırın.
6- macOS "Uygulama doğrulanamadı" uyarısı alırsanız İlk çalıştırmada macOS güvenlik nedeniyle uygulamanın açılmasını engelleyebilir. Bu normaldir. Bunun için:
a- Sistem Ayarları → Gizlilik ve Güvenlik menüsünü açın.
b- Sayfanın alt kısmında "Mukavele açılması engellendi" uyarısını göreceksiniz.
c- "Yine de Aç" düğmesine tıklayın.
d- Açılan onay penceresinde tekrar "Aç" seçeneğini seçin.

Not: Bu işlemi yalnızca ilk kurulumda bir kez yapmanız yeterlidir. Sonraki çalıştırmalarda uygulama normal şekilde açılacaktır. Mukavele şu anda Apple tarafından notarize edilmiş (Apple onaylı) bir uygulama değildir. Bu nedenle macOS ilk çalıştırmada ek güvenlik onayı istemektedir. Uygulama doğrudan benim tarafımdan geliştirilmiş ve GitHub üzerinden yayımlanmaktadır. İlerleyen sürümlerde Apple notarization sürecinin de tamamlanması planlanmaktadır.
